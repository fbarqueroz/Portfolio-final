About me

Hello everyone, my name is Fabián Barquero. I’m a frontend-focused fullstack developer and a Computing Engineering student with professional experience building and maintaining scalable web applications for enterprise environments. I’ve worked extensively with modern frontend frameworks and CMS platforms such as Adobe Experience Manager (AEM), focusing on accessibility, performance, and clean, maintainable code. On the frontend side, I build component-based interfaces using technologies like JavaScript (ES6+), React, and Angular, ensuring responsive layouts and design consistency through reusable UI components and design systems. On the backend, I’ve contributed to API integrations and application logic using Node.js and Ruby on Rails, collaborating closely with cross-functional teams to deliver end-to-end solutions. I enjoy understanding systems from both the frontend and backend perspectives, translating complex requirements into user-centered digital experiences, and continuously improving code quality and scalability. Outside of development, I stay active through sports, play percussion instruments, and create digital illustrations inspired by anime, cartoons, and Japanese cinema.
